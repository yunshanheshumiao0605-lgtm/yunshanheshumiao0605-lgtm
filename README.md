**把好奇的念头，做成日常的小作品。**

我是 **Ellen，北京师范大学心理学专业研究生**。喜欢阅读、学习和探索，对人、技术和生活中的新可能保持好奇。持续学习是我的习惯，学习能力也是我尝试新事物的一份底气。

**职业生涯的前半场**，我一直在阿里巴巴、字节跳动、京东等公司从事组织与人才工作，积累了对人与组织的理解。

**走向职业生涯的后半场**，我希望把过去的经验与新的兴趣连接起来，给自己更多学习、创造和体验的空间，探索下一段值得投入的事业。

AI 是我正在学习和实践的新领域。我从自己的日常需要出发，做一点工具，试一些想法，让学习有输出，让好奇心有具体的样子。

「一念有形」记录我的小作品、学习心得，以及职业与生活的新探索。
