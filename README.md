# 一念有形 — Ellen 的好奇心实验室

**把好奇的念头，做成日常的小作品。**

我是 **Ellen，北京师范大学心理学专业研究生，也是一名心理咨询师**，有自己的工作室。

**职业生涯的前半场**，我长期从事组织与人才工作，也有自己的创业经历。人与组织如何成长，是我持续关注的话题。

工作之外，我喜欢**阅读、游泳和潜水**，也喜欢学习和探索陌生的领域。学习能力是我的一份底气，让我愿意带着好奇，在新的领域里重新做一个初学者。

如今，我正在尝试和探索下一段职业生涯。**我希望下一程，能走出不一样的样子。** 带上过去的经验，也给新的兴趣、创造和生活方式留出空间。

AI 是我正在探索的新工具。我从自己的日常需要出发，把一些想法做成可以使用的小作品。「一念有形」记录这些作品、学习中的发现，以及职业与生活的新尝试。
