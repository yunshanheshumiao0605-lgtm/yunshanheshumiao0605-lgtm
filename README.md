### [一日有痕 · Daily Trace](https://github.com/yunshanheshumiao0605-lgtm/daily-trace)

把每日清单、习惯打卡和轻量复盘放在一起，给每天留下一点看得见的痕迹。

- **安排今天**：整理每日必做事项和可选任务。
- **积累习惯**：打卡，并查看每个月的坚持。
- **留住日常**：轻量复盘，支持本地 Obsidian / Markdown 同步。

本地优先 · 浏览器运行 · 数据保存在本地
